## 2. 背景と目的

### 2.1 背景
当初、Google AI Edgeの最新推論スタック「LiteRT-LM」を活用したApple Siliconローカル推論基盤として発足した。
しかし、実際のエンタープライズ（1,000人〜10,000人規模の大企業）導入においては以下の高度な実務ニーズが不可欠であることが判明した：
1. **ハイブリッド推論の要請**:
   機密情報やオフライン環境ではローカルモデル（Gemma / LiteRT-LM）で推論しつつ、複雑な長文思考や高度な業務分析ではクラウドの最新Gemini（Gemini 3.5 Flash Lite等）をシームレスに切り替えて利用したい。
2. **非エンジニアでも迷わないナレッジ管理（CMS化 & 万能ファイル取込）**:
   Word、Excel、PowerPoint、PDF、CSV、TXT等のあらゆる業務文書をそのまま投入でき、さらに「交通費の上限額が変更された」「特定の規程の1行だけを修正したい」といった**部分文面の直接編集・追加・削除**を、総務・人事・法務等の一般従業員がWord感覚でブラウザから即座に行えるUIが必要である。
3. **大企業向け階層型委譲ユーザー管理（Delegated RBAC / 各部署での自律完結）**:
   数千人〜1万人規模の企業において、全社員の入社アカウント発行・異動時権限変更・日常パスワード再発行・退職停止を最高システム管理者（Admin）1名だけで行うと業務がパンクする。各部署のリーダーである「編集長（Editor / 部門管理者）」に自部署の閲覧者（Viewer）・編集長（Editor）の管理を委譲し部署内で完結させるとともに、管理者（Admin）アカウントの保護と権限昇格の絶対禁止を両立する厳格なガバナンスが必要である。
4. **エンタープライズ・ゼロトラストセキュリティ & 監査統制**:
   未ログイン時の社内データ完全遮断（Zero-State Gate & 401 Guard）、ロール別アクセス制御（RBAC）、APIキーの完全秘匿、ユーザー操作監査ログ（誰が/何を/どこから/成否）の1年間保管と自動パージが不可欠。さらに、OWASP Top 10準拠の脆弱性対策（Google OIDC IDトークンのRSA暗号署名検証、Stored DOM XSS根絶、タイミング攻撃防御、25MBリクエスト制限、CSPヘッダー送出、設定ファイルパーミッション0600強制）を徹底する。
5. **ブルートフォース総攻撃防護（アカウントロックアウト）& 無操作セッション失効（アイドルタイムアウト）**:
   悪意ある第三者や内部端末からの総当たり辞書攻撃を遮断するため、同一アカウントでの「連続5回失敗による5分間アカウント一時ロック」および管理者・部門管理者による即時解除機能を配備。さらに離席時の不正操作を防止するため、ログインから24時間の絶対有効期限に加え「最終操作から30分無操作時の自動セッション切断」を導入する。
6. **大企業NAT/プロキシ対応 & 動的レート制限管理**:
   10,000人規模の大企業で全社員が単一のプロキシ/NAT IPを共有している場合でも一括遮断が起きないよう、チャットAPIの制限軸をログインアカウント単位（`session.username`）へ分離。さらにログインAPIは60秒スライディングウィンドウ方式（`Retry-After` 算出）とし、管理画面から制限値を動的に調整（0=無制限）可能とする。
7. **全画面多言語化（i18n: 日本語・英語・繁体字中国語）& 国際化レイアウト可読性最適化**:
   グローバル企業や多言語対応チームでの利用を見据え、全画面テキスト・トースト・ダイアログ・テーブル・バッジの3言語（日本語 `ja`、英語 `en`、繁体字中国語 `zh-TW`）ワンクリック切り替えおよび `localStorage` 永続化を実現。単語長が伸びる英語や視認性が重要な繁体字中国語において、表示枠からのはみ出し、文字切れ、レイアウト崩れを一切発生させない `word-break` / `line-height` / `flex` レスポンシブ可読性デザインを徹底する。
8. **ユーザー別チャット完全分離 & ChatGPT形式スレッド管理**:
   他人の質問内容や社内機密が漏洩しないマルチテナント分離と、会話の永続化・個別削除・一括消去機能を提供。
9. **高度なRAGグラウンディング & 自然言語の意図解釈**:
   「日本の総理大臣を聞いているのに台湾のナレッジを勝手に補足する」といったハルシネーションの根本排除（排他エンティティ制御）と、「電車の定期代」「テレワーク」など社員の口語表現・表記揺れをLLMが事前に理解して正式規程を確実にヒットさせるクエリ展開機能を提供する。

### 2.2 目的
本プロジェクトは、**「LiteRT-LMの極限オンデバイス性能」**と**「Google公式GeminiネイティブSDKによるクラウド最新推論」**を統一し、一般社員が直感的に操作できる**「Web管理画面（ナレッジブロックCMS ＋ チャット）」**、**「エンタープライズ・ゼロトラストセキュリティ基盤（脆弱性対策・ブルートフォース自動防護・アイドルタイムアウト・動的レート制限）」**、**「大企業向け階層型委譲アクセス制御（Delegated RBAC）」**、**「LLM事前理解・意図解釈エンジン」**、**「3言語i18n対応」**、および**「MCPツール連携」**を備えた安全安心な社内AIナレッジ基盤を構築する。

## 4. プロジェクトスコープ

### 4.1 対象範囲（In-Scope）
1. **ハイブリッド推論コア**:
   * ローカル推論: LiteRT-LM（macOS Apple Silicon Metal GPU / CPUフォールバック、MTP対応）
   * クラウド推論: Google GenAI公式ネイティブSDK（`google-genai`）による最新GeminiモデルAPI接続
   * 公開中Geminiモデルのリアルタイム探索（ボタン1発取得）・カード詳細表記・ディスク永続化
2. **万能マルチフォーマット取込 & 直感型CMS**:
   * Word (.docx), Excel (.xlsx), PowerPoint (.pptx), PDF (.pdf), CSV, TXT の直接パース・抽出・透明性レポート
   * 文境界優先チャンキング（句点・改行優先分割）
   * ナレッジブロック単位の部分追加・直接編集・即時削除（CRUD）
3. **インテリジェントRAG & ゼロハルシネーション防護**:
   * **LLM事前クエリ理解・意図解釈・同義語展開エンジン（QueryExpander）**: 口語・表記揺れを社内正式用語に自動展開
   * **排他エンティティ不整合検知**: 国名（日本・台湾等）や役職（大統領・総理大臣等）の不一致を検索段階で根本除外
   * **引用リンク完全サプレッション**: ナレッジに記載がない場合、無関係な補足や参照資料リンクの付与を100%遮断
4. **エンタープライズ・セキュリティ & 認証ゲート**:
   * ゼロステート認証ゲート（未認証時の全UI完全非表示・ログイン画面のみ露出）
   * 401 Unauthorized API Guard（全REST APIの厳格トークン保護）
   * 多階層RBAC（Admin / Editor / Viewer / Auditor）および階層型委譲ユーザー管理
   * **脆弱性対策・ゼロトラスト防御**:
     * 開発用 switch エンドポイントの本番完全無効化（403 Forbidden）
     * Google OIDC IDトークンのRSA暗号署名検証（JWKS）必須化
     * 管理画面のインラインイベントハンドラ全廃による Stored DOM XSS 根絶
     * ダミーPBKDF2計算によるユーザー列挙・タイミング攻撃防御
     * 25MB リクエストペイロード上限（413 Payload Too Large）
     * 一般社員に対するセンシティブ情報（人事メモ・ロック状態等）の完全マスキング
     * 設定ファイル（`system_settings.json`）のパーミッション `0600` 強制
     * セキュリティヘッダー（CSP, Permissions-Policy, nosniff, DENY, XSS-Protection）送出
   * **ブルートフォース総攻撃防護（アカウントロックアウト）**: 連続5回パスワード失敗で5分間一時自動ロック、残り時間案内、管理者・部門管理者による即時アンロック
   * **セッション・無操作タイムアウト（Idle Timeout）**: ログイン後24時間上限＋最終操作から30分無操作時の自動セッション破棄・再ログイン誘導
   * **大企業NAT対応スライディングウィンドウ・レート制限**:
     * ログインAPI: 60秒スライディングウィンドウ（`Retry-After` 秒数算出）
     * チャットAPI: ログインアカウント単位（`session.username`）分離（1万人のNAT共有環境でも一括遮断なし）
     * リバースプロキシ `X-Forwarded-For` クライアントIP抽出
     * 管理画面からの動的レート制限変更・無制限化（0設定）
   * ゼロトラスト・APIキー完全秘匿 & ログサニタイズ
   * ユーザー操作監査ログ（誰が/何を/どこから/成否）および障害診断ログ（7〜365日保存・自動パージ）
5. **全画面3言語多言語化（i18n）& 国際化レイアウト保護**:
   * 日本語（`ja`）、英語（`en`）、繁体字中国語（`zh-TW`）のワンクリック切り替え
   * フレーズ辞書・DOM走査・MutationObserver・トースト・ダイアログの完全翻訳
   * `word-break`、`:lang(zh-TW)` 専用フォント/行間設定による枠はみ出し・文字切れ防止
6. **macOS Apple Silicon 環境最適化**:
   * Apple Silicon Metal GPU アクセラレーションおよび POSIX パーミッション保護
   * ワンクリック環境構築スクリプト（`setup_env.sh`）および Web ポータル起動（`start_web.py`）
7. **ChatGPT形式会話履歴管理**:
   * マルチテナント・ユーザー間完全分離（他ユーザーのチャット非露出）
   * スレッド一覧・自動命名・個別削除・一括全消去（UI/API）
8. **外部ツール拡張性（MCP Server）**:
   * Model Context Protocol (MCP) エンドポイント配備
9. **Google Workspace 統合連携基盤（DOC-GWS-001）**:
   * **ハイブリッドSSO統合認証**: Google OIDC / OAuth 2.0 によるワンクリックログイン、社内ドメイン制限（`hd`）、JITプロビジョニング、ローカルPBKDF2認証との完全共存。
   * **Google Drive 常時増分同期**: Changes API による差分検知、Docs/Sheets/Slides の自動エクスポート・万能パース、文境界チャンキング＆Qdrant自動更新。
   * **削除追従パージ＆権限統制**: Drive上で削除された資料の即時ベクトル完全消去、共有ドライブ・フォルダ指定ホワイトリスト管理、フォルダ単位のロール権限統制。
   * **リアルタイム同期ダッシュボード**: 同期進捗・最終同期日時・エラー件数のUI可視化および「今すぐDriveと同期（Sync Now）」機能。

### 4.2 対象外（Out-of-Scope）

## 5. 成功の定義（KPI）

* **文面修正の即時反映時間**: ブラウザでの文面修正からRAG回答への反映が 3秒以内。
* **一般従業員操作性**: 非エンジニアがマニュアルなしで「Office/PDF追加」「文面編集」「チャット質問」「言語切替」を完遂可能。
* **検索適合率 & ハルシネーション防止**: 口語表現の検索漏れ0件、および対象外事項への勝手な補足・誤引用0件。
* **エンタープライズ適合性**: 未認証アクセスの100%遮断、全ユーザー操作の完全な監査証跡記録、OWASP Top 10基準の完全充足。
* **macOS環境稼働率**: macOS (Apple Silicon Metal) 環境において追加修正ゼロで100%稼働・自動テスト合格。
